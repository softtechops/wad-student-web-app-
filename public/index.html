Teacher Practical Demonstration Guide (F12 DevTools)
For College / Viva Analysis
1

Open Developer Tools

Press F12 (or Ctrl + Shift + I) in Chrome/Edge, then click on the Network tab.

2

Trigger HTTP Methods

Click [ GET ], [ POST ], [ PUT ], or [ DELETE ]. Watch the request appear in real-time in the Network list.

3

Inspect Headers & Status

Click any request in Network to show the teacher:

  • Status Code: 200 OK / 201 Created / 404 Not Found
  • Headers: Content-Type: application/json
  • Payload: The JSON sent in request body
  • Response: The JSON returned by Python server
4

Demonstrate 404 Not Found

Click "Test 404 (Wrong URL)" or request a non-existing Student ID to show 404 Not Found handling.
